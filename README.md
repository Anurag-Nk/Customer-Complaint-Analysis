# Customer-Complaint-Analysis

# 📊 Customer Complaint Dashboard

An interactive **Tableau Customer Complaint Dashboard** designed to analyze customer complaints across products, years, request types, and U.S. states. The dashboard provides a centralized view of complaint volume and helps identify trends, complaint patterns, and geographic concentration.

---

## 📖 Short Description / Purpose

The **Customer Complaint Dashboard** transforms customer complaint data into interactive visual insights.

It enables users to explore complaints across different **financial products, years, request channels, and states**, helping identify complaint trends, high-volume products, frequently used submission methods, and geographic patterns.

The dashboard is designed to support **customer service teams, business analysts, and decision-makers** in understanding complaint behavior and identifying areas that may require attention.

---

# 🛠️ Tech Stack

The dashboard was built using:

- 📊 **Tableau Desktop** – Main platform used for data visualization and dashboard development.
- 📂 **Data Preparation** – Data cleaning, organization, and preparation for analysis.
- 📈 **Interactive Visualizations** – Bar charts, area/line charts, KPI cards, and geographic visualizations.
- 🗺️ **Geographic Analysis** – State-level complaint analysis using maps.
- 🎛️ **Interactive Filters** – Product and map-type selectors for dynamic dashboard analysis.
- 📁 **File Format** – Tableau workbook (`.twb` / `.twbx`) and PNG dashboard previews.

# 📂 Data Source

**Source:** Customer Complaint Dataset

The dataset contains customer complaint information across different financial products and complaint submission channels.

The dashboard analyzes dimensions including:

- Complaint Date
- Product
- State
- Request Type / Submission Channel
- Number of Complaints
- Year

The data was prepared and structured for visualization and trend analysis in Tableau.

# ✨ Features / Highlights

## 📌 Business Problem

Organizations receive large volumes of customer complaints through multiple channels and across different products and geographic regions.

Analyzing raw complaint records makes it difficult to quickly answer questions such as:

- Which products receive the most complaints?
- How have complaint volumes changed over time?
- Which states have the highest number of complaints?
- Which channels do customers use most frequently?
- Which products show increasing or decreasing complaint trends?
- Where are complaints geographically concentrated?

---

## 🎯 Goal of the Dashboard

The main objective of this dashboard is to provide an interactive analytical view that:

- Monitors overall complaint volume.
- Compares complaints across financial products.
- Identifies yearly complaint trends.
- Analyzes complaint submission channels.
- Provides state-wise geographic analysis.
- Enables users to dynamically switch between products.
- Supports data-driven customer service decisions.

# 📊 Dashboard Walkthrough

## 1️⃣ KPI Overview

The top section provides a quick summary of total complaints and product-wise complaint distribution.

### Key KPIs

- **Total Complaints:** 72,431
- **Bank Services:** 9,690
- **Checking/Services:** 12,192
- **Credit Card:** 18,910
- **Mortgage:** 11,918
- **Others:** 19,721

These KPIs provide an immediate overview of complaint volume and the contribution of different products.

---

## 2️⃣ Complaint Per Year

The **Complaint Per Year** visualization shows the percentage distribution of complaints across different years.

This helps identify changes in complaint activity over time and compare complaint patterns between selected products.

---

## 3️⃣ State-Wise Complaints

The dashboard provides two ways to analyze geographic complaint distribution:

### 🗺️ Map View

Displays complaints geographically across U.S. states, allowing users to identify states with higher complaint volumes.

### 🔲 Tile Chart View

Provides an alternative state-wise visualization where each state displays its complaint count.

A **Select Map** filter allows users to switch between the available geographic visualization formats.

---

## 4️⃣ Request Type Analysis

The **Request Type** visualization analyzes how customers submitted their complaints.

Available submission channels include:

- Web
- Referral
- Phone
- Postal Mail
- Fax
- Email

This helps organizations understand the most frequently used complaint channels and customer communication preferences.

---

## 5️⃣ Year Trend

The **Year Trend** visualization displays the number of complaints over time.

It helps identify:

- Increasing complaint activity
- Declining complaint activity
- Peak complaint periods
- Changes in complaint volume across years

---

## 6️⃣ Product Selector

The interactive **Select Product** filter allows users to analyze complaints for specific products, including:

- Bank Services
- Checking/Services
- Credit Card
- Mortgage
- Others

Changing the selected product dynamically updates the dashboard's KPIs and visualizations.

---

# 🎛️ Interactive Features

The dashboard includes interactive controls that allow users to perform focused analysis.

### Select Product

Filter the complete dashboard based on a specific financial product.

### Select Map

Switch between:

- Map
- Tile Chart

for state-wise complaint analysis.

### Cross-Filtering

Selecting elements within the visualizations allows users to explore related complaint information interactively.

# 📈 Key Insights

The dashboard provides insights into:

- Total customer complaint volume.
- Product-wise complaint distribution.
- Year-over-year complaint trends.
- State-wise complaint concentration.
- Most frequently used complaint submission channels.
- Differences in complaint patterns across financial products.

For the overall dashboard view, **Credit Card complaints account for approximately 26.11% of total complaints**, while **Others account for approximately 27.23%**.

The submission-channel analysis also shows that **Web** is a major complaint submission channel, followed by **Referral and Phone**.
